# Masking
- Masking (tạo mặt nạ) trong CSS thông qua thuộc tính `mask-image`.
- Áp dụng kĩ thuật lồng ghép hình ảnh (như cách chúng ta đắp mặt nạ lên), ẩn hoặc hiện các phần cụ thể trong 1 phần tử.
- Nguyên lí hoạt động của nó:
    - Chỗ nào trên `mask-image` có màu: Hình ảnh gốc sẽ hiển thị ở trên.
    - Chỗ nào trên `mask-image` trong suốt: hình ảnh gốc sẽ bị ẩn đi.
## Another prop 
- Trong kĩ thuật masking có 9 property phụ hỗ trợ cho `masking`
    1. `mask-clip`: which area is affected by a mask image
    2. `mask-composite`
    3. `mask-image`
    4. `mask-mode`
    5. `mask-origin`
    6. `mask-position`
    7. `mask-repeat`
    8. `mask-size`
    9. `mask-type`
