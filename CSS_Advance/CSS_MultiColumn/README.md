# Multi-Column layout:
- CSS có thể thiết kế trang web thành bố cục column giống như các trang báo.
- Bằng các sử dụng property chính đó là `column-count`

## column-count
- Khởi tạo bố cục layout column
- EX: `column-count: 3;`

## column-gap
- Khoảng cách giữa các cột với nhau

## column-rule
- `column-rule` có 3 thuộc tính giống như `border`.
    1. `column-rule-style` hiệu chỉnh đường kẻ giữa các cột thuộc tính giống đường viền của `border-style`
    2. `column-rule-width` điều chỉnh độ dày của đg viền
    3. `column-rule-color`
## column-span
- Mở rộng giống với `column-span` trong `table`
## column-width
- Độ rộng của cột đó.
