# CSS Image Filters.
1. `blur()`: làm mờ hình ảnh.
2. `brightness()`: điều chỉnh độ sáng  
3. `contrast()`: điều chỉnh độ tương phản
4. `drop-shadow()`: đổ bóng cho ảnh
5. `grayscale()`: đổi sắc thái màu của ảnh (đen->trắng) 
6. `hue-rotate()`: đổi góc độ màu, màu sẽ bị xoay tròn theo ý muốn
7. `invert()`: thêm màu đối lập
8. `opacity()`: điều chỉnh độ trong suốt
9. `saturate()`: độ đậm nhạt của màu ảnh()
10. `sepia()`: chỉnh màu cổ điển
