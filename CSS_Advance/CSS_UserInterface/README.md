# User interface
- User interface là các thuộc tính tùy chỉnh theo giao diện của người dùng (hoàn toàn chủ động)
- User interface có 2 thuộc tính chính đó là:
    1. `resize`.
    2. `outline-offset`.
## resize
- Thuộc tính này giúp phóng to thu nhỏ 1 thẻ lại
- Có 4 giá trị tất cả:
    1. `horizontal`: điều chỉnh kích cỡ theo chiều ngang **width**.
    2. `vertical`: điều chỉnh kích cỡ theo chiều dọc.
    3. `both`: điều chỉnh theo 2 hướng
    4. `none`: (Default)
## outline-offset
- Tùy chỉnh đg viền outline-offset bên ngoài margin
