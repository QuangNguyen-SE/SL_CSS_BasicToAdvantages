# JAVASCRIPT & CSS
- JS là 1 trong 3 ngôn ngữ basic và tối quan trọng trong thiết kế web.
- JS rất mạnh được sử dụng thông qua nhiều framework lớn như (REACT, NEXT.JS, NODE.JS, EXPRESS.JS,...)

# Vậy JS đóng vai trò gì trong việc thiết kế 1 trang web.
- Nếu nói HTML là xương sống basic của 1 trang web.
- CSS là da trang trí cho trang web.
- JS chính là bộ não của trang web.
- Dựa vào quy tắc CRUD giống các ngôn ngữ back-end, JS làm việc với các data, các biến, dữ liệu đc truyền tải từ database lên backend và hiển thị ra trang web nhờ JS (fletch api).
- JS có khả năng tác động tới các node trong cây DOM, xử lí các event từ user hay các yếu tố thay đổi trong cây DOM. 
>JS là 1 ngôn ngữ đa dụng và rất mạnh mẽ với các bộ thư viện đa dạng, kể cả nó có thể hỗ trợ back-end (ExpressJS, NodeJS,...)
